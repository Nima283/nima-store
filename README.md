# نِلی استایل — فروشگاه اینترنتی پوشاک

یک پروژه شروع فروشگاه فارسی با Next.js، TypeScript، Tailwind CSS و Prisma/SQLite.

## امکانات فعلی
- صفحه اصلی راست‌چین، واکنش‌گرا و فارسی
- جست‌وجو و فیلتر دسته‌بندی
- صفحه جزئیات محصول با انتخاب سایز و رنگ
- سبد خرید مبتنی بر localStorage
- ثبت سفارش و ذخیره سفارش در SQLite
- کاهش موجودی کالا هنگام ثبت سفارش
- پنل مدیر با ورود رمز عبور، مشاهده سفارش‌ها و افزودن/ویرایش قیمت و موجودی/حذف محصولات

## راه‌اندازی محلی

پیش‌نیاز: Node.js نسخه 20 یا بالاتر.

```bash
npm install
cp .env.example .env
```

مقادیر `ADMIN_PASSWORD` و `ADMIN_SECRET` را در `.env` تغییر بده. سپس:

```bash
npx prisma migrate dev --name init
npm run db:seed
npm run dev
```

سایت در `http://localhost:3000` اجرا می‌شود و پنل مدیریت در `/admin` قرار دارد.

## نکات مهم پیش از انتشار
- تصاویر و اطلاعات محصولات نمونه هستند؛ تصاویر، قیمت‌ها، موجودی و توضیحات واقعی خودت را جایگزین کن.
- ثبت سفارش در این نسخه فعال است، اما درگاه پرداخت بانکی متصل نیست. برای دریافت وجه واقعی باید درگاه معتبر و تأیید callback سمت سرور اضافه شود.
- برای محیط عملیاتی، SQLite را به PostgreSQL منتقل کن، `ADMIN_SECRET` قوی و تصادفی قرار بده، ورود مدیر را به سامانه احراز هویت استاندارد مجهز کن، محدودیت نرخ درخواست و اعتبارسنجی کامل اضافه کن و سایت را روی HTTPS منتشر کن.
- اطلاعات تماس، شبکه‌های اجتماعی، قوانین ارسال/مرجوعی و حریم خصوصی باید با اطلاعات واقعی فروشگاه تکمیل شوند.
- فونت Vazirmatn از Google Fonts بارگذاری می‌شود؛ برای میزبانی داخلی می‌توان فایل فونت را محلی کرد.

## ساختار
- `app/` صفحات و APIهای Next.js
- `components/` اجزای رابط کاربری
- `lib/` ابزارها و اتصال دیتابیس
- `prisma/` مدل‌ها و داده‌های اولیه
